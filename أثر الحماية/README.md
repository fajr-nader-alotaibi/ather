# ATHAR | أثر الحماية — Guardians of Nature

## وصف اللعبة

«أثر الحماية» لعبة مغامرات ومنصات ثنائية الأبعاد تدور في عالم طبيعي سحري تضرر توازنه. يستكشف اللاعب **غابة الأمل**، ويجمع البذور النورانية، ويساعد رفيقه على استعادة النباتات وإصلاح الجسر، لتعود الحياة والألوان إلى البيئة.

تركّز التجربة على الاستكشاف والتعاون مع الرفيق وحل لغز بيئي قصير، بروح دافئة مناسبة للعائلة. هذه اللعبة مشروع مستقل عن لعبة «أثر خطى» الموجودة في جذر المستودع.

## تشغيل اللعبة

- المحرك: Godot 4.7 أو أحدث.
- افتح Godot، اختر **Import**، وحدد `project.godot` في هذا المجلد.
- شغّل المشروع بزر **F5**. يستخدم المشروع وضع عرض Compatibility.

## التحكم

- الحركة: `A` و`D` أو الأسهم.
- القفز: `Space` أو `W` أو السهم للأعلى.
- التفاعل: `E`.
- الإيقاف المؤقت: `Esc`.
- تظهر أزرار لمس عند التشغيل على جهاز يدعم اللمس.

## محتوى هذه النسخة

تتضمن الشريحة الحالية مرحلة «غابة الأمل»، حركة وقفزًا، رفيقًا محليًا، جمع ثلاث بذور، استعادة نبات وجسر، وواجهة عربية وإنجليزية. اللعب عبر الإنترنت والمراحل الإضافية والتصدير للهواتف غير منفذة بعد.

راجع `docs/ROADMAP.md` لخطة التطوير و`docs/TEST_REPORT.md` لما تم التحقق منه.
