# ATHAR | أثر — Guardians of Nature

**نسخة أولية قابلة للتطوير لمحرك Godot 4** — المرحلة الأولى: *غابة الأمل / Forest of Hope*.

تم إنشاء هذا المشروع من الصفر لأن الملفات المتاحة عند بدء العمل كانت وثيقة المتطلبات والصورة المرجعية فقط، ولم تكن هناك ملفات مشروع Godot سابقة لفحصها أو متابعة العمل عليها.

## التشغيل

1. فك ضغط `ATHAR_Godot_Prototype.zip`.
2. افتحي Godot 4، ثم اختاري **Import**.
3. اختاري ملف `project.godot` الموجود داخل المجلد.
4. افتحي المشروع واضغطي **F6** لتشغيل المشهد الرئيسي، أو **F5** لتشغيل المشروع.
5. من شاشة البداية اضغطي **ابدئي الرحلة / Begin Journey**.

المشروع يستخدم GDScript وصور PNG محلية، ولا يحتاج إلى تنزيل إضافات أو الاتصال بخدمة خارجية.

## التحكم

- **A / D** أو الأسهم: الحركة.
- **Space** أو **W** أو سهم الأعلى: القفز.
- **E**: التفاعل مع كائن الغابة أو البوابة، ودفع الصندوق عند الاقتراب منه.
- **Esc**: الإيقاف المؤقت والمتابعة.
- زر اللغة أعلى الشاشة: التبديل بين العربية والإنجليزية.

## هدف النموذج الأولي

- استكشاف مقطع جانبي من غابة خيالية.
- جمع **3 بذور نورانية**.
- إنقاذ كائن الغابة بالاقتراب منه والضغط على **E**.
- دفع الصندوق الخشبي.
- بعد جمع البذور وإنقاذ الكائن، تفعيل الرموز بالترتيب: القمر ثم الورقة ثم النجمة. الخطأ يعيد ترتيب الرموز من البداية.
- الوصول إلى البوابة القديمة والتفاعل معها بعد إكمال الهدف.
- إكمال الرحلة لعرض شاشة النجاح.

## ما أُنشئ

- مشروع Godot 4 ومشهد رئيسي.
- حركة أفقية وقفز مع **Coyote Time** و **Jump Buffer**.
- كاميرا جانبية تتبع اللاعب.
- خلفية غابة مع انزياح Parallax بسيط، وأرضيات مرسومة برمجيًا وصور PNG أصلية مصممة لهذا النموذج.
- شخصية مستكشفة، رفيق مضيء، بذور، كائن قابل للإنقاذ، صندوق، بلورات وفطر مضيء وبوابة.
- واجهة أولية بالعربية والإنجليزية، وقائمة بداية وإيقاف مؤقت ونجاح.
- نقاط رجوع بسيطة إذا سقط اللاعب خارج المسار.

## الحالة الحالية والقيود

هذا **نموذج لعب للمرحلة الأولى** وليس النسخة الكاملة من وثيقة ATHAR. لا يحتوي حاليًا على:

- المراحل الأربع الكاملة.
- اللعب الجماعي الحقيقي عبر الإنترنت أو نظام غرف لأربعة لاعبين.
- رفيق ذكاء اصطناعي يقدم حلولًا للألغاز؛ الرفيق الحالي يتبع اللاعب بصريًا فقط.
- تحكم لمس نهائي للجوال أو إعداد تصدير Android جاهز.
- نظام حفظ دائم أو إنجازات أو تخصيص شخصيات.
- نظام إعلانات.
- لغز مرايا أو ماء أو لغز تعاوني؛ التحدي الحالي هو جمع البذور وإنقاذ الكائن وفتح البوابة.
- اختبار تشغيل داخل محرّك Godot أو تصدير نهائي؛ لم يكن Godot مثبتًا في بيئة الإنشاء المتاحة، لذلك أُعدّت الملفات دون الادعاء بأنها شُغّلت أو اختُبرت داخل المحرك. افتحي المشروع في Godot 4 وأرسلي أي رسالة خطأ تظهر، إن وجدت، لإصلاحها على أساسها.
