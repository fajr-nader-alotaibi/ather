# سجل الأصول

جميع الصور داخل `assets/` أُنشئت خصيصًا لهذا النموذج باستخدام رسم برمجي محلي عبر Pillow، ولم تُنسخ من اللعبة المرجعية أو من لعبة تجارية.

| الملف | الاستخدام |
|---|---|
| `forest_background.png` | خلفية الغابة الخيالية والضباب والبلورات البعيدة |
| `player.png` | شخصية المستكشفة |
| `companion.png` | الرفيق السحري المضيء |
| `seed.png` | بذرة نورانية قابلة للجمع |
| `forest_creature.png` | كائن الغابة الذي يحتاج إلى إنقاذ |
| `wood_crate.png` | صندوق قابل للدفع |
| `ancient_gate.png` | البوابة القديمة في نهاية المرحلة |
| `glow_mushroom.png` | فطر مضيء للزينة |
| `blue_crystal.png` | بلورة زرقاء للزينة |
| `restored_plant.png` | نبتة تظهر بعد إنقاذ الكائن |
| `rune_moon.png` | رمز القمر في لغز الترتيب |
| `rune_leaf.png` | رمز الورقة في لغز الترتيب |
| `rune_star.png` | رمز النجمة في لغز الترتيب |

لا توجد حاليًا ملفات صوتية خارجية أو أصول خارجية تتطلب نسبًا أو تراخيص إضافية.
